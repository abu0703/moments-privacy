這個應用程式是什麼 / What this app is

for_claude_auto 是一個個人使用的自動化工具，只由擁有者本人使用，用來把擁有者自己製作的影片與照片，發佈到擁有者自己管理的 Facebook 粉絲專頁「片刻 Moments」與 Instagram 帳號 @moments.by.ai，並查看這些貼文的成效。它不對外開放、不提供登入給其他人使用。

for_claude_auto is a personal automation tool used only by its owner. It publishes the owner's own videos and photos to the Facebook Page "片刻 Moments" and the Instagram account @moments.by.ai, both managed by the owner, and reads the performance of those posts. It is not offered to the public and no one else signs in to it.

我們收集哪些資料 / Data we collect

這個應用程式不收集任何其他使用者的個人資料。它只存取擁有者自己的粉專與 IG 帳號，用到的權限如下：

  • pages_show_list、pages_read_engagement：找到擁有者管理的粉專、讀取自己貼文的互動數據
  • pages_manage_posts：把影片與照片發佈到擁有者的粉專
  • instagram_basic、instagram_content_publish：把同樣的內容發佈到擁有者的 IG 帳號
  • read_insights、instagram_manage_insights：讀取自己貼文的播放數、觸及等成效數據

成效數據只有彙總數字（例如播放次數、按讚數），不包含觀看者的身分。

The app does not collect personal data from any other user. It only accesses the owner's own Page and Instagram account, using the permissions listed above to find the Page, publish content to it and to Instagram, and read aggregate performance numbers (such as plays and likes) of the owner's own posts. These numbers do not identify viewers.

資料如何儲存與使用 / How data is stored and used

  • 存取權杖（access token）只存放在擁有者自己的電腦上，不會上傳到任何其他伺服器。
  • 成效數據只用來讓擁有者了解自己的內容表現，不會出售、出租或分享給任何第三方，也不會用於廣告投放。

The access token is stored only on the owner's own computer and is never uploaded elsewhere. Performance data is used only so the owner can see how their own content performs. It is never sold, rented or shared with any third party, and is not used for advertising.

資料刪除說明 / Data deletion instructions

因為這個應用程式不收集其他使用者的資料，所以沒有任何使用者資料需要刪除。

如果你曾經授權過這個應用程式，可以隨時移除它的存取權：

  1. 開啟 Facebook，前往「設定和隱私」→「設定」。
  2. 選擇「應用程式和網站」（或「商家整合」）。
  3. 找到 for_claude_auto，點「移除」。

移除後，這個應用程式就無法再存取你的任何資料。如有其他刪除需求，請來信聯絡（見下方）。

Because this app does not collect data from other users, there is no user data to delete. If you have ever authorized it, you can remove its access at any time: open Facebook → Settings & privacy → Settings → Apps and Websites (or Business Integrations), find for_claude_auto and click Remove. After removal the app can no longer access any of your data. For any other deletion request, contact us below.
